Translator Settings

Gemini API Key

Enter your own Gemini API key. The key is stored locally in Chrome storage.

Privacy

  • Page text is sent only when you trigger a page translation.
  • Uploaded file content is sent only when you trigger file translation.
  • No telemetry or analytics is collected by this extension by default.
  • Google Gemini API applies its own terms and privacy handling to the transferred content.

Supported Formats

  • Plain text (.txt)
  • Markdown (.md)
  • HTML (.html)

PDF and DOCX support require additional parsing libraries and are intentionally not included in this starter build.
